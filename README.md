# 세법 오답노트 텔레그램 봇

간격반복학습(spaced repetition) 원리를 적용해, 세법 오답 문제를 정해진 시간마다
텔레그램으로 자동 발송하고 학습 현황을 추적하는 개인용 복습 도구입니다.

## 왜 만들었나

수습회계사 시험을 준비하는 후배가 세법의 높은 휘발성으로 고민하는 것을 듣고, 오답을 집중적으로 반복할 수 있는 챗봇을 만들게 되었습니다. 

이미 매일 확인하는 메신저(텔레그램)에 문제가 알아서 찾아오게 만들고,
**틀린 문제일수록 더 자주, 맞춘 문제일수록 점점 덜 자주** 나오도록 해서
사람이 복습 스케줄을 직접 관리하지 않아도 되게 만드는 것이 목표였습니다.

## 주요 기능

- **가중치 기반 문제 출제**: 틀린 횟수가 많고 레벨이 낮은 문제일수록 뽑힐 확률이
  높아지는 알고리즘 — 취약한 부분에 학습이 자동으로 더 배분됨
- **레벨업 간격반복 스케줄링**: 맞히면 다음 복습일이 1일→3일→7일→14일→30일→60일→90일
  순으로 점점 늘어나고, 틀리면 즉시 1일 후로 초기화
- **정해진 시간 자동 발송**: 하루 중 지정된 시각(기본값: 08:30, 17:50, 18:00, 18:30)에
  텔레그램으로 문제 자동 도착
- **인라인 버튼 기반 피드백**: 정답 확인 → 맞았다/틀렸다 기록까지 탭 몇 번으로 완료
- **`/stats` 통계 확인**: 누적 정답률과 오늘 복습 대상 수를 즉시 확인

## 기대효과

수동으로 복습 스케줄을 관리하는 인지 부담을 없애고, 학습 시간을 취약 영역에
자동으로 집중시켜 동일한 공부 시간 대비 암기 효율을 높이는 것을 의도했습니다.

## 사용 기술

- **Python**
- **python-telegram-bot** — 봇 명령어 핸들러, 인라인 버튼, `job_queue` 기반 스케줄링
- **pandas** — CSV 기반 문제 데이터 관리(정규화, 가중치 계산, 통계 집계)
- **zoneinfo** — `Asia/Seoul` 타임존 기준 정시 발송

## 실행 방법

### 1. 텔레그램 봇 토큰 발급

텔레그램에서 **@BotFather**와 대화 → `/newbot` → 안내에 따라 봇 이름 설정 →
발급되는 토큰을 복사해둡니다.

### 2. 환경변수로 토큰 등록

```bash
# Mac/Linux
export TAX_BOT_TOKEN="발급받은 토큰"

# Windows (PowerShell, 영구 등록)
setx TAX_BOT_TOKEN "발급받은 토큰"
```

### 3. 문제 데이터 준비

`tax_question_answer.csv` 파일을 같은 폴더에 두고, 최소한 `question`, `answer`
두 열을 포함시킵니다:

```csv
question,answer
"부가가치세 예정신고 대상은?","..."
```

### 4. 패키지 설치 및 실행

```bash
pip install python-telegram-bot pandas
python tax_bot.py
```

실행 후 텔레그램에서 본인이 만든 봇에게 `/start` 또는 `/quiz`를 보내면
그 채팅방으로 자동 발송이 시작됩니다.

## 보안 관련 안내

봇 토큰은 코드에 직접 쓰지 않고 환경변수(`TAX_BOT_TOKEN`)로만 받도록 되어
있습니다. 토큰이 외부에 노출된 적이 있다면 반드시 BotFather에서 재발급받으세요.

## 확장 가능한 방향

- 문제 데이터를 CSV 대신 데이터베이스로 전환해 다중 사용자 지원
- 오답 패턴을 분석해 취약 주제(부가세/법인세 등) 자동 태깅
- 생성형 AI로 오답 문제에 대한 추가 해설 자동 생성
